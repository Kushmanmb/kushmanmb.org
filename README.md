# Fleeing 5-0

A performance-optimized slot machine game.

## Prerequisites

- Node.js 18+ 
- npm

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

## Webpack bundle

```bash
npm run webpack
```

## Test

```bash
npm test
```

## Run the game

Open `dist/index.html` in your browser after building.

## Project structure

- `src/` - game source files
- `assets/` - symbol assets
- `build.js` - build script
- `test.js` - game logic tests
